# 바둑 한 수

브라우저에서 실행되는 Canvas 기반 바둑 게임입니다. 빠른 내장 AI부터 다운로드형 브라우저 모델까지 선택할 수 있으며, 사용자 차례에 요청한 경우에만 AI 추천 수를 보여줍니다.

- 플레이: https://garden417.github.io/baduk/
- 기본 판 크기: 19×19
- 선택 가능한 판 크기: 19×19, 15×15

## 주요 기능

- 컴퓨터 대전과 2인 대전
- 돌 잡기, 자살수 방지와 패 처리
- 한 수 쉼과 두 번 연속 쉼 이후 중국식 계가
- 19×19와 15×15 판 크기 선택 및 브라우저 저장
- 빠른 AI, 작은 브라우저 모델, 실전용 b18 모델 선택
- 사용자가 원할 때만 표시되는 AI 추천 수
- 모바일 터치 오착수 방지
- 게임 종료 후에도 가능한 무르기
- AI 대전에서 사용자 수와 AI 응답을 함께 되돌리는 무르기

## 게임 방법

흑이 먼저 시작하며 백에는 6.5집의 덤이 적용됩니다. 상대 돌의 모든 활로를 막으면 그 돌을 잡습니다. 두 대국자가 연속으로 `한 수 쉼`을 선택하면 중국식 방식으로 계가하고 승부를 결정합니다.

마우스에서는 교차점을 한 번 클릭하면 바로 착수합니다. 터치 기기에서는 후보 위치와 돌이 먼저 표시되며, `여기에 착수`를 눌러야 실제로 돌을 놓습니다. `취소`를 누르거나 다른 교차점을 선택하여 후보를 변경할 수 있습니다. 후보를 표시하기 전에 자살수와 패 등 착수 가능 여부를 검사합니다.

판 크기를 바꾸면 현재 대국은 초기화됩니다. 선택한 크기는 `localStorage`의 `baduk-board-size`에 저장됩니다. 저장된 값이 없는 신규 사용자의 기본값은 19×19입니다.

## AI 엔진

### 1. 빠른 AI

- 게임에 내장된 기본 버전
- 별도 다운로드 없이 즉시 실행
- 휴리스틱 기반으로 빠르지만 바둑 실력은 제한적

### 2. 작은 브라우저 모델

- 약 3.8MB의 연습용 모델
- 서버 없이 사용자 브라우저에서 실행
- 한 수 계산이 느릴 수 있으며 기기 발열과 배터리 사용량이 증가할 수 있음
- 모델 크기가 작아 바둑 실력은 제한적

### 3. 실전용 b18 모델

- 약 96MB의 다운로드형 모델
- 사용자가 다운로드 버튼을 눌러 준비
- WebGPU 또는 WASM을 통해 사용자 기기에서 실행
- 최초 다운로드와 초기화에 시간이 필요함
- 모바일이나 저사양 기기에서는 계산 지연, 발열과 높은 배터리 사용량이 발생할 수 있음

세 엔진 모두 일반 AI 착수와 사용자용 추천 수 기능에 연결됩니다. `AI 추천 수 보기`를 누른 경우에만 현재 사용자 입장에서 추천 위치를 계산하고 표시합니다. 추천을 요청하지 않으면 힌트가 나타나지 않습니다.

## 무르기

대국이 끝난 뒤에도 결과 화면의 `마지막 수 무르기`를 사용할 수 있습니다. 두 번 연속 한 수 쉼으로 계가가 끝난 경우에도 종료 전 상태로 돌아갈 수 있습니다.

AI 대전에서 사용자가 둔 뒤 AI가 응답했다면 두 수를 함께 되돌려 사용자가 다시 수를 선택할 수 있게 합니다. AI가 계산 중일 때에는 상태 충돌을 방지하기 위해 무르기가 잠시 비활성화됩니다.

## 기술 구조

- `index.html`: 대국 화면, AI 선택, 추천과 조작 컨트롤
- `styles.css`: 반응형 레이아웃과 터치 확인 UI
- `app.js`: 바둑 규칙, 렌더링, 계가, AI 연결, 추천과 무르기
- `katago-engine/`: 브라우저 AI 작업자와 모델 어댑터
- `katago-engine/badukAdapter.js`: 게임 좌표와 모델 좌표 변환
- HTML Canvas: 바둑판과 돌 렌더링
- 별도의 추론 서버 없음

15×15와 19×19를 모두 지원하기 위해 모델 좌표 변환은 고정된 19가 아니라 현재 `board.length`를 사용합니다. 별 위치, 중앙점, 격자 간격과 AI 기준 좌표도 판 크기에 따라 동적으로 계산됩니다.

## 로컬 실행

모델 작업자와 브라우저 보안 정책 때문에 정적 HTTP 서버로 실행해야 합니다.

예시:

```powershell
python -m http.server 8765
```

그다음 `http://127.0.0.1:8765/baduk/`에 접속합니다.

브라우저 모델을 검사할 때에는 개발자 도구에서 모델 다운로드, WebGPU 또는 WASM 초기화 오류도 함께 확인하는 것이 좋습니다.

## 브라우저 지원 및 제한사항

- 최신 Chrome 또는 Edge에서 WebGPU 사용을 권장
- WebGPU가 없으면 환경에 따라 WASM으로 실행될 수 있음
- 모델 다운로드에는 네트워크와 브라우저 저장 공간이 필요함
- 모바일에서는 큰 모델 사용 시 탭이 느려지거나 메모리 부족이 발생할 수 있음
- 터치 2단계 확인은 포인터 종류가 `touch`일 때만 적용됨
