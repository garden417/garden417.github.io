# 오목 한 판

브라우저에서 바로 즐기는 Canvas 기반 오목 게임입니다. 별도의 서버나 설치 없이 컴퓨터 또는 다른 사람과 대국할 수 있습니다.

- 플레이: https://garden417.github.io/omok/
- 기본 판 크기: 19×19
- 선택 가능한 판 크기: 19×19, 15×15

## 주요 기능

- 컴퓨터 대전과 2인 대전
- 흑돌 선공과 가로·세로·대각선 오목 판정
- 새 게임, 점수 기록, 무르기
- 게임이 끝난 뒤 결과 화면에서 마지막 수 무르기
- AI 대전에서 사용자 수와 AI 응답을 한 번에 되돌리는 무르기
- 19×19와 15×15 판 크기 선택 및 브라우저 저장
- 모바일 터치 오착수 방지

## 게임 방법

흑돌이 먼저 시작합니다. 가로, 세로 또는 대각선으로 자신의 돌 다섯 개를 먼저 연속해서 놓으면 승리합니다.

마우스로 플레이할 때는 원하는 교차점을 한 번 클릭하면 바로 착수합니다. 터치 기기에서는 교차점을 누르면 후보 위치가 먼저 표시됩니다. 위치를 확인한 후 `여기에 착수`를 누르면 돌이 놓이고, `취소`를 누르면 선택이 해제됩니다.

판 크기를 바꾸면 현재 게임은 초기화됩니다. 선택한 크기는 `localStorage`의 `omok-board-size`에 저장되어 다음 방문에도 유지됩니다. 저장된 값이 없는 신규 사용자의 기본값은 19×19입니다.

## AI와 무르기

오목 AI는 외부 서버나 별도의 다운로드 모델을 사용하지 않습니다. 브라우저 안에서 현재 판을 평가하는 휴리스틱과 탐색 로직으로 다음 수를 선택합니다.

AI 대전에서 사용자가 둔 뒤 컴퓨터가 응답했다면 `무르기`는 두 수를 함께 제거하여 사용자가 다시 선택할 수 있는 시점으로 돌아갑니다. 사용자의 수가 즉시 게임을 끝낸 경우에는 그 마지막 수만 되돌립니다. 승리 후에도 결과 화면의 `마지막 수 무르기`를 사용할 수 있으며 승리선, 점수와 종료 상태도 함께 복구됩니다.

## 기술 구조

- `index.html`: 화면 구조와 게임 컨트롤
- `styles.css`: 반응형 레이아웃, 바둑판 주변 UI와 터치 확인 UI
- `app.js`: 판 상태, 승리 판정, AI, 렌더링, 크기 선택과 무르기
- HTML Canvas: 바둑판과 돌 렌더링
- 외부 백엔드 없음

배포 저장소에서는 이 파일들이 `omok/` 디렉터리에 있습니다. 저장소 루트의 `index.html`은 개인 포트폴리오 페이지이므로 오목 배포 시 덮어쓰면 안 됩니다.

## 로컬 실행

정적 파일 서버로 저장소 루트를 연 뒤 `/omok/`으로 접속합니다. ES 모듈과 브라우저 보안 정책 때문에 HTML 파일을 직접 여는 것보다 HTTP 서버 사용을 권장합니다.

예시:

```powershell
python -m http.server 8765
```

그다음 `http://127.0.0.1:8765/omok/`에 접속합니다.

## 브라우저 지원 및 참고 사항

- 최신 Chrome, Edge, Safari, Firefox 권장
- 터치 2단계 확인은 포인터 종류가 `touch`일 때만 적용됩니다.
- 데스크톱 마우스 조작은 기존의 한 번 클릭 착수 방식을 유지합니다.
- 브라우저 저장소를 삭제하면 판 크기 설정도 기본값으로 초기화됩니다.
