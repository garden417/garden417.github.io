# 중국어 뜻 검수실

중국어 단어와 한국어 뜻을 사람이 하나씩 대조하고, 검수 결과를 원본 형식의 XLSX 파일로 다시 저장하는 정적 웹 도구입니다.

- 서비스: https://garden417.github.io/chinese-tone/review/
- 검수자용 매뉴얼: [chinese-tone-reviewer-manual.txt](./chinese-tone-reviewer-manual.txt)
- 연계 학습 게임: https://garden417.github.io/chinese-tone/

## 주요 기능

- XLSX 검수표에서 중국어, 병음, 성조, HSK 급수와 원본 한국어 뜻 표시
- 각 항목을 `정확`, `수정 필요`, `보류`, `미검수`로 분류
- 수정 한국어 뜻과 검수 메모 입력
- 입력할 때마다 브라우저의 IndexedDB에 자동 저장
- 같은 브라우저에서 마지막 작업과 첫 미검수 항목부터 이어하기
- 다른 브라우저나 기기에서는 이전에 내려받은 XLSX를 불러와 이어하기
- 원본 서식을 유지한 새 XLSX 작업 파일 생성
- 상태별 항목 수와 진행률 확인

## 사용 흐름

1. 검수용 XLSX 파일을 선택합니다.
2. 중국어와 원본 한국어 뜻을 비교합니다.
3. 검수 결과를 선택하고 필요한 경우 수정 뜻 또는 메모를 입력합니다.
4. 작업을 마칠 때 `작업 엑셀 만들기`를 누릅니다.
5. 준비된 `완성 파일 다운로드` 링크로 최신 XLSX를 저장합니다.

브라우저 자동 저장은 임시 백업입니다. 작업을 마칠 때마다 XLSX 파일도 내려받는 것을 권장합니다.

## 지원하는 검수표 형식

앱은 워크시트에서 다음 열 이름을 찾아 데이터를 읽습니다.

| 필수 열 | 용도 |
| --- | --- |
| 검수번호 | 항목 순서 |
| pair_id | 같은 발음의 단어 쌍 식별자 |
| 세트명 | HSK 카드 세트 이름 |
| 쌍 구분 | A·B 단어 구분 |
| 중국어 | 검수 대상 한자 |
| 병음 | 발음 |
| 성조 | 성조 번호 |
| HSK 급수 | 참고 난이도 |
| 원본 한국어 뜻 | 검수 대상 번역 |
| 검수 결과 | 미검수·정확·수정 필요·보류 |
| 수정 한국어 뜻 | 검수자가 제안한 번역 |
| 검수 메모 | 보류 사유 또는 기타 의견 |

현재 번역 검수표는 500개 단어쌍, 즉 1,000개의 개별 중국어 단어를 포함합니다. 엑셀의 기존 제목, 요약 영역, 셀 서식과 데이터 유효성 검사는 다운로드 파일에서도 유지됩니다.

## 개인정보와 파일 처리

이 서비스는 별도의 서버나 데이터베이스를 사용하지 않습니다. 선택한 XLSX와 검수 기록은 사용자의 브라우저 안에서만 처리되며 외부 서버로 업로드되지 않습니다. GitHub Pages는 정적 HTML, CSS, JavaScript 파일만 제공합니다.

공용 기기에서는 작업을 마친 뒤 다운로드 파일을 확보하고 브라우저 사이트 데이터를 삭제하세요.

## 권장 환경

최신 Chrome, Edge 또는 Safari를 권장합니다. 카카오톡 내부 브라우저는 파일 선택이나 다운로드가 원활하지 않을 수 있으므로, 링크를 외부 브라우저에서 여는 것이 안전합니다.

## 기술 구성

- 정적 HTML, CSS, JavaScript
- [SheetJS Community Edition](https://docs.sheetjs.com/) — XLSX 읽기
- [JSZip](https://stuk.github.io/jszip/) — 원본 XLSX 내부 XML을 수정해 서식 보존
- IndexedDB — 브라우저 자동 저장
- GitHub Pages — 정적 배포

## 로컬 실행

저장소 루트에서 정적 파일 서버를 실행한 뒤 `/chinese-tone/review/`를 엽니다.

```bash
python -m http.server 4176
```

`file://`로 직접 열면 브라우저의 파일·저장소 보안 정책 때문에 일부 기능이 제한될 수 있습니다.
