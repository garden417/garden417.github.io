중국어–한국어 뜻 검수 웹페이지 사용 매뉴얼
==========================================

검수 페이지
https://garden417.github.io/chinese-tone/review/


1. 검수 목적
------------

각 중국어 단어와 원본 한국어 뜻이 정확하게 대응하는지 확인합니다.
오역, 의미 누락, 품사 오류 또는 지나치게 부자연스러운 설명이 있으면 올바른 뜻을 기록합니다.


2. 시작하기
-----------

1) 카카오톡에서 받은 검수 페이지 링크를 Chrome, Edge 또는 Safari로 엽니다.
   카카오톡 내부 브라우저에서는 파일 선택이나 다운로드가 원활하지 않을 수 있습니다.

2) 웹페이지에서 "엑셀 파일 선택"을 누릅니다.

3) 전달받은 XLSX 검수표를 선택합니다.

4) 웹페이지가 엑셀을 확인한 후 첫 번째 미검수 단어를 보여줍니다.

파일과 검수 내용은 사용자의 브라우저 안에서만 처리되며 외부 서버로 전송되지 않습니다.


3. 화면에서 확인할 내용
-----------------------

- 중국어: 검수할 단어
- 병음: 단어의 발음
- 성조: 병음의 성조
- HSK 급수: 참고용 난이도
- 원본 한국어 뜻: 정확성을 판단할 대상
- pair_id와 쌍 구분: 같은 발음의 A·B 단어를 구분하는 식별자

뜻은 반드시 중국어 한자를 기준으로 판단합니다.
같은 pair_id의 A와 B 단어도 뜻은 각각 독립적으로 검수합니다.


4. 검수 결과 선택 방법
----------------------

[정확]

원본 한국어 뜻이 적절한 경우 선택합니다.

- 핵심 의미가 정확함
- 한국어 표현이 자연스러움
- 대표적인 의미가 적절하게 포함됨

"수정 한국어 뜻"과 "검수 메모"는 비워 둡니다.


[수정 필요]

다음 중 하나라도 해당하면 선택합니다.

- 중국어 단어와 뜻이 일치하지 않음
- 중요한 대표 의미가 빠짐
- 다른 한자의 뜻이 입력됨
- 품사가 잘못됨
- 한국어 표현이 부자연스러움
- 설명이 오해를 유발함

"수정 한국어 뜻"에 권장하는 뜻을 반드시 입력합니다.
필요하면 "검수 메모"에 수정 이유를 적습니다.


[보류]

즉시 판단하기 어렵거나 추가 확인이 필요한 경우 선택합니다.

- 문맥에 따라 의미가 크게 달라짐
- 사전이나 추가 자료 확인이 필요함
- 중국어 원어민 또는 다른 검수자의 의견이 필요함
- 원본과 수정안의 우열을 판단하기 어려움

"검수 메모"에 보류 이유나 확인할 사항을 반드시 입력합니다.


[미검수로 되돌리기]

실수로 잘못 판정했거나 나중에 처음부터 다시 판단하려는 경우 사용합니다.


5. 수정 뜻 작성 원칙
--------------------

- 가장 일반적이고 대표적인 뜻을 앞에 씁니다.
- 여러 의미는 세미콜론(;)으로 구분합니다.
- 가능한 한 간결한 사전식 표현을 사용합니다.
- 동사는 "~하다", 형용사는 "~하다" 또는 "~한", 명사는 명사형으로 통일합니다.
- 중국어 원문에 없는 설명을 지나치게 추가하지 않습니다.
- 용법 설명이 필요하면 괄호를 사용합니다.
- 원본 한국어 뜻은 직접 바꾸지 않고 수정안을 별도 입력란에 작성합니다.

병음, 성조 또는 HSK 급수 오류를 발견하면 뜻이 정확하더라도 검수 메모에 기록합니다.
확신이 없는 내용을 임의로 고치지 말고 보류로 표시합니다.


6. 여러 번 나누어 작업하기
--------------------------

검수 결과, 수정 뜻과 메모는 입력할 때마다 현재 브라우저에 자동 저장됩니다.

같은 브라우저에서 다시 접속하면:

1) 첫 화면에 저장된 작업의 완료 개수가 표시됩니다.
2) "이어서 작업"을 누릅니다.
3) 이전에 작업하던 기록과 미검수 단어가 복원됩니다.

브라우저 자동 저장은 편의를 위한 임시 저장입니다.
작업을 마칠 때마다 반드시 엑셀 파일도 내려받아 백업해 주세요.


7. 작업 엑셀 저장하기
---------------------

1) 화면의 "작업 엑셀 만들기"를 누릅니다.

2) 엑셀이 준비되면 나타나는 "완성 파일 다운로드"를 누릅니다.

3) 검수 결과가 반영된 새 XLSX 파일이 다운로드됩니다.

4) 파일 이름에는 검수한 항목 수와 날짜가 들어갑니다.

예:
chinese-tone-meaning-review_검수_137개_2026-08-03.xlsx

5) 다운로드한 파일을 안전한 위치에 보관합니다.

브라우저는 원본 파일을 직접 덮어쓰지 않습니다. 항상 새로운 작업 파일을 만듭니다.


8. 다른 브라우저나 기기에서 계속하기
------------------------------------

1) 이전 작업에서 내려받은 최신 XLSX 파일을 준비합니다.

2) 새 브라우저에서 검수 페이지를 엽니다.

3) "엑셀 파일 선택"을 누르고 최신 XLSX 파일을 선택합니다.

4) 웹페이지가 엑셀의 정확, 수정 필요, 보류, 미검수 상태를 읽습니다.

5) 첫 번째 미검수 단어부터 작업을 이어갑니다.

항상 가장 최근에 내려받은 XLSX 파일을 불러와 주세요.


9. 기존 브라우저 기록과 엑셀 기록이 함께 발견될 때
----------------------------------------------------

같은 데이터에 대한 브라우저 기록과 엑셀 기록이 모두 있으면 선택 창이 나타납니다.

- "엑셀 기록만 사용": 불러온 XLSX 내용만 사용합니다.
- "브라우저 기록 함께 적용": 브라우저 자동 저장 내용도 함께 적용합니다.

어느 기록이 최신인지 확실하지 않다면 검수 완료 개수가 더 많은 쪽을 기준으로 선택합니다.


10. 작업 완료 후 전달하기
------------------------

1) 미검수 개수가 0인지 확인합니다.

2) 보류 항목이 있으면 가능한 범위에서 다시 확인합니다.

3) 마지막으로 "작업 엑셀 만들기"와 "완성 파일 다운로드"를 차례로 누릅니다.

4) 다운로드한 최신 XLSX 파일을 카카오톡으로 의뢰자에게 전달합니다.

JSON 파일은 수정하거나 전달할 필요가 없습니다.


11. 문제가 생겼을 때
--------------------

- 카카오톡 내부 브라우저라면 Chrome 또는 Safari로 다시 여세요.
- 파일이 열리지 않으면 XLSX 확장자인지 확인하세요.
- 잘못된 파일을 불러왔다면 "다른 엑셀 열기"를 누르세요.
- 다운로드가 보이지 않으면 브라우저의 다운로드 목록 또는 파일 앱의 다운로드 폴더를 확인하세요.
- 브라우저 기록이 사라졌다면 마지막으로 내려받은 XLSX를 다시 불러오세요.
